  <h3>E aí, tudo bem? Me chamo Gabriel.</h3>

  Sou desenvolvedor backend com foco em C# e .NET, graduando em Engenharia de Software pela FIAP e atualmente estagiário na Vivo. Tenho conhecimentos em Programação Orientada a Objetos, princípios SOLID, Design Patterns e desenvolvimento de APIs RESTful com ASP.NET Core.



  Nos meus projetos de portfólio, aplico esses conceitos no desenvolvimento de soluções com regras de negócio, autenticação e autorização, integração com bancos de dados relacionais e boas práticas de desenvolvimento. Utilizo Entity Framework Core, LINQ, SQL, xUnit e Moq, além de Git e GitHub para versionamento e Docker para conteinerização.



  Também tenho familiaridade com Linux, depuração, documentação de APIs e conceitos de CI/CD, além de conhecimentos introdutórios em AWS. Busco aprimorar continuamente minhas habilidades em engenharia de software, desenvolvendo aplicações bem estruturadas, testáveis e de fácil manutenção.

  <h3>Meus projetos</h3>

  <a href="https://github.com/panicq-dev/desafio-picpay">
    <img src="https://img.shields.io/badge/Desafio_PicPay-000000?style=for-the-badge&logo=github&logoColor=white" valign="middle" alt="Desafio PicPay">
  </a>

  API RESTful desenvolvida com C# e .NET para simular uma plataforma de pagamentos, com regras de negócio para transferências, validações, persistência com Entity Framework Core e testes automatizados com xUnit e Moq. O projeto também utiliza Docker para conteinerização.

  <a href="https://github.com/panicq-dev/desafio-itau">
    <img src="https://img.shields.io/badge/Desafio_Itaú-000000?style=for-the-badge&logo=github&logoColor=white" valign="middle" alt="Desafio Itaú">
  </a>

  Implementação em C# e .NET de um desafio de backend inspirado no Itaú, com API RESTful para transações e estatísticas. O projeto explora regras de negócio, manipulação de dados e testes automatizados com xUnit.


  <a href="https://github.com/panicq-dev/auth-system">
    <img src="https://img.shields.io/badge/Authentication_System-000000?style=for-the-badge&logo=github&logoColor=white" valign="middle" alt="Authentication System">
  </a>

  Sistema de autenticação e autorização desenvolvido com ASP.NET Core Identity, Entity Framework Core e JWT. Implementa gerenciamento de usuários e papéis (User/Admin), emissão de tokens e refresh tokens, explorando segurança e controle de acesso em aplicações backend.
