  <h3>E ai, tudo bem? Me chamo Gabriel.</h3>
Sou estudante de Engenharia de Software na FIAP e gosto de transformar ideias em soluções que realmente funcionem na prática. Tenho foco no ecossistema .NET com C#, mas também curto desenvolver com Kotlin, Python e Java - linguagens que mais gosto.
Além do desenvolvimento, tenho interesse em dados e análise de informações, utilizando MySQL e Power BI.
Fora da tecnologia, estou quase sempre assistindo séries, jogando ou descobrindo filmes novos. Tenho um perfil muito movido por curiosidade, análise e inconformismo, sempre buscando aprender mais, explorar novas ideias e evoluir constantemente, tanto no lado técnico quanto pessoal. Para mim, aprender e inovar é essencial!
